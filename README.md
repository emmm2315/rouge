# 双界行者（Dual World Walker）

基于 Java 21 / JavaFX Canvas 的单机俯视角 Roguelike 动作游戏。光影两种形态共享战场和敌人生命，通过切界、灼痕、技能与终结技组织战斗。

本文对应 2026-09-15 的功能基线（`5e9df94`）。旧需求书及设计稿用于保留设计背景，实际规则以本文、代码和最终测试记录为准；隐藏路线、档案进度、图鉴与成就的变更见 [2026-09-15 功能同步说明](docs/2026-09-15-progress-and-hidden-room-update.md)。

## 启动与验证

需要 JDK 21 或更高版本，并配置 JAVA_HOME。首次使用 Maven Wrapper 需要下载依赖。

```powershell
.\mvnw.cmd javafx:run
.\mvnw.cmd test
.\mvnw.cmd package
# 可选：使用真实 JavaFX 离屏渲染进行视觉检查
.\mvnw.cmd test "-Dplayer.preview=true"
```

macOS / Linux 使用 `./mvnw`。也可在 IDEA 中作为 Maven 项目打开，运行 `com.phantomcorridor.Launcher`。

依赖为 JavaFX Controls / Media 21.0.6、JUnit Jupiter 5.12.1。模型层不依赖 JavaFX；控制器处理输入，Canvas 视图读取模型绘制。暂停停止模拟时间，资源恢复、冷却和施法都随之冻结。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准、持续普攻 | 鼠标移动、按住左键 |
| 当前形态技能 | Q / E，分别触发技能 1 / 技能 2 |
| 当前形态终结技 | R，每次按下触发一次 |
| 普通切界 | Ctrl，不消耗相位 |
| 强化切界 | Shift+Ctrl，消耗 100 相位 |
| 闪避 | Space，沿移动方向；无移动输入时沿朝向 |
| 拾取、宝箱、事件、商店确认 | F |
| 丢弃装备 / 满栏替换 | 1、2、3；战斗中不可主动丢弃 |
| 取消替换、暂停 / 继续 | Esc；P 也可暂停 / 继续 |
| 全屏 | F11 / Alt+Enter |

商店先按 F 选中商品，再按 F 确认；走远取消选择。满栏时选择替换槽位，旧装备落在地上。装备选择面板阻止普攻和技能操作；Esc 先取消选择，再按才暂停。死亡结算只能点击按钮重开或返回菜单；通关结算保留 R 重开、M 返回菜单。

## 普攻、技能蓝条与相位

普攻不消耗蓝量，维持稳定基础输出：光形态发射光弹，基础间隔 0.45 秒；影形态使用半径 155、角度 330° 的近战斩击，基础间隔 0.55 秒，基础伤害系数为 1.20（以近身风险换取更高单次伤害）。武器仍可改变弹体、段数、范围、前摇和攻击间隔。

原攻击充能条改为 Q/E 技能共用蓝条：

- 初始和基础上限为 16 点，技能每次消耗 6 点。
- 每 1.5 秒自然恢复 1 点，空条回满需 24 秒；恢复一次技能的消耗需 9 秒。
- Q、E 各有独立的 4 秒冷却，两种形态共用蓝条；两个技能都随时间恢复资源。
- 通用、双属性道具首次获得时仍各增加 1 点容量，只补新增的 1 点，不回满已消耗的蓝量。
- HUD 显示蓝量、相位、技能与终结技冷却；释放失败会显示资源不足、冷却中或目标被墙遮挡等原因。

相位专供终结技或主动强化切界：

| 来源或用途 | 数值 |
| --- | --- |
| 初始 / 上限 | 0 / 100 |
| 自动恢复 | 每秒 0.5；仅游戏模拟推进时恢复 |
| 击杀非召唤敌人 | 按物种结算：普通怪 2～5 点、精英 6～7 点、Boss 13～16 点 |
| 相位碎片 | 每个单位 10 点 |
| 普通攻击或 Q 引爆灼痕 | 每层 1 点 |
| 挨打、空挥、普攻直接命中 | 不直接回复相位 |
| R 终结技 | 消耗 80 点，独立冷却 30 秒 |
| Shift+Ctrl 强化切界 | 消耗 100 点，与终结技争用相位 |

终结技本身引爆灼痕不回复相位；非召唤敌人的击杀奖励仍正常结算。召唤物不提供击杀相位或金币。切界、离房和换层不重置技能 / 终结技冷却，也不回满蓝量、相位；新局才重置。纯自然恢复从零到满需 200 秒，即使通过战斗快速攒满，也受终结技 30 秒冷却限制。

## 双形态技能与终结技

伤害系数以玩家基础伤害 10 为基准，再应用当前形态的装备 / 道具加成、难度、敌人弱点、灼痕及防御。以下都是一次施法对每个符合条件的敌人结算一次，不按特效帧数重复扣血。

| 按键 / 形态 | 名称 | 范围 | 伤害系数 | 前摇 |
| --- | --- | --- | --- | --- |
| Q 光 | 凝光爆破 | 鼠标方向最远 260，落点半径 100 | 3.0 | 0.24 秒 |
| E 光 | 星辉棱刺 | 鼠标方向最远 190，落点半径 145、110° 扇形 | 2.4 | 0.32 秒 |
| Q 影 | 裂影斩 | 以施法位置为中心、瞄准方向 140° 扇形，半径 210 | 4.0 | 0.24 秒 |
| E 影 | 幽冥锁链 | 以施法位置为中心、瞄准方向 85° 扇形，半径 175 | 3.2 | 0.32 秒 |
| R 光 | 黎明裁决 | 以施法位置为中心，半径 330 圆形 | 8.0 | 0.45 秒 |
| R 影 | 永夜葬刃 | 以施法位置为中心，半径 280 圆形 | 10.0 | 0.45 秒 |

施法位置、方向、形态和目标点在按键成功时锁定，范围提示不会跟着移动。施法期间仍可半速移动，但不能普攻、闪避、切界或启动另一招；受到伤害不会打断，死亡会取消。离开房间会取消尚未结算的施法，已经支付的资源及冷却不退还。不要在过门前启动尚未完成的技能。

光技能的目标必须与施法位置之间无遮挡；所有技能从作用中心到敌人的视线也必须无遮挡。判定使用实际敌人受击框与当前世界的实体墙。终结技在释放时清除范围内允许被清除的敌方弹幕，不提供额外无敌帧。武器的普攻替换方案不会改变 Q / E / R 的几何范围、段数或资源成本；余震等普攻轮次效果不会被技能重复触发。

## 切界、移动与受击

- Ctrl 随时可在切界冷却结束后使用；保留相位，切界后减速 0.3 秒。Shift+Ctrl 必须满相位，消耗后清除周围半径 118 内可清除弹幕，并给予 0.3 秒无敌。两种切界共用 0.3 秒冷却，成功切界清除旧的玩家普攻与未完成普攻。
- 相位墙只在当前世界生效。敌方弹幕、反弹和开火视线按玩家当前世界检查墙体，弹体的原光影属性和伤害类型不变。共有墙与房间边界始终阻挡。
- 冲刺距离 150、持续 0.18 秒，结束后冷却 1 秒，冲刺全程免伤；沿途进行墙体与房门碰撞检查。
- 玩家初始生命 100、护盾 30。护盾先承伤，打穿后的伤害溢出到生命；每层开始回满护盾，装备变化不会回满护盾。药剂每瓶回复 10 点生命。
- 有效受击触发闪白、击退与 0.65 秒无敌，不能靠挨打获取相位。击退也遵守墙体碰撞。
- 光伤铺最多三层、持续六秒的灼痕；影伤消耗灼痕，每层追加 0.4 基础影伤系数。敌人有弱光、弱影及光影配合破防等属性。

## 难度与成长

| 模式 | 每波敌人 | 敌方伤害（标准为 1） | 同层 Boss 血量（标准为 1） | 每件装备额外加算伤害 |
| --- | --- | --- | --- | --- |
| 简单 | 3 | 0.50 | 0.50 | 0 |
| 标准 | 3～4 | 1.00 | 1.00 | 0 |
| 困难 | 3～4 | 1.15 | 1.35 | +5% |
| 屌炸天 | 3～4 | 1.30 | 1.40 | +10% |

普通敌人生命、防御与玩家输出的难度刻度仍为 0.5 / 1 / 1.5 / 2。敌人生命每层增加基础值的 25%；基础防御每层 +1、封顶 3 后按难度缩放。困难 Boss 在原倍率上削减 10%，屌炸天削减 30%。

每间战斗房按种子生成 1～3 波，波间间隔 1.2 秒，数量不随层数继续堆高。困难首波、屌炸天每波保底一只精英，每波最多一只；其他波次精英概率为简单 15%、标准 35%、困难 55%，随机精英从第二层开放。普通怪出生后有 0.8 秒入场缓冲。

装备栏固定三槽，同名装备可叠加数值。高难度的每槽额外伤害对两种形态、普攻和技能均有效，满栏分别 +15% / +30%；不放大独立的生命、减伤、速度等效果。卸装立即失去对应加成，HUD 装备伤害汇总包含它。

8 件改变普攻方案的武器按稳定优先级同时启动，不再让后装备的攻击方式被覆盖：贯日长杖、炽核权杖、折镜法球、棱光三叉杖、夜坠重剑、归影双刃、环月镰、蚀界仪。其他装备包含护盾容量、生命上限、光伤、影伤、受击减伤、短时加速、切界攻速窗口和每第四轮普攻震波。具体数值见 `EquipmentType`、`AttackProfile`、`GameConfig`；局内可悬停查看装备说明。

## 探索与敌人

一局五层，每层击败首领后走近传送门按 F 前进，第五层穿过传送门通关。生命、金币、装备、技能资源及冷却跨层保留，护盾每层回满。地图按种子可复现，包含入口、战斗、奖励、商店、事件、Boss 和隐藏房。

每层有一条由种子确定入口形态（光或影）的隐藏支路。来源战斗房必须已经清场，且玩家处于该支路要求的形态时，暗门才会显示、可进入；不满足形态时，房门和小地图入口提示都不显示。首次进入获得 20 金币，重进不重复发奖。隐藏支路不替代 Boss 或层间出口，也不引入第三种角色形态。

房间宝箱、掉落、商店商品和事件结果在本层进出时保留。普通战斗房和事件房有多种障碍组合，生成时检查通路；入口、奖励和商店保留开放布局。小地图显示连通关系、商店、事件、宝箱、传送门等状态；隐藏门与隐藏房只在要求形态下显示，战斗时小地图精简显示。

共 15 种敌人：灯魇、晶狼、傀儡、法师、处刑者、鸣钟者、裂隙守望者，以及铲角甲虫、行囊孢子、钩尾翼蝠、棱镜炮蟹、双镰螳爵、织巢蛛后、根冠古树、镜砂术士。第一层固定守望者，后四层从五个扩展首领中按种子选取不同物种。首领半血切入另一形态，拥有独立招式、弹幕与召唤机制。

敌人两界共享位置与血量，切界后继续追击和施法。范围预警、多段命中去重、反弹弹体、孢子落地、根篱阻挡、裂隙召唤等按各自技能规则处理。菜单、探索与 Boss 战有独立循环 BGM 和切换淡入淡出。

## 主角资源与视觉

主角使用 `character_assets_v3_atlas_rebuild_20260913`：双形态、四方向、八动作共 256 张 RGBA 帧，320×256 画布、原始锚点 (160,140)，默认按 0.5 倍绘制。

运行资源在 `src/main/resources/com/phantomcorridor/sprites/player_v3`，随 JAR 打包，不依赖启动目录。执行 `./tools/Import-CharacterAssets.ps1` 可重新复制资源，并从 JSON manifest 生成 `animations.properties`。

- 待机固定首帧，避免素材轮廓漂移；首次加载按同方向移动首帧校准待机身高与脚底位置，再缓存到统一透明画布。
- 移动按实际行走距离顺序播放 0→1→2→3，每 100 像素完成一个步态周期；停止时冻结步态、继续行走时接续，转向不重置。加载时只平移走路帧以对齐头部，避免轮廓漂移，不缩放走路帧；斜向方向判断带浮点容差。
- 普攻按成功出招播放，技能使用 attack 动作，终结技使用 finisher_cast，施法动作时长适配前摇。闪避、受击、虚化与切界有独立动作。
- 人物和 VFX 分离，斩击特效对应判定半径与角度；技能有蓄力范围与释放波纹。冲刺残影保存生成时的形态、方向和姿势。
- V3 不含死亡帧，倒地仍使用旧素材。原始帧只有四个关键阶段，仍有美术细节漂移；时序调整不能替代更完整的手工动画。

层间传送门采用竖向石质门框、金色 / 紫色符文和中央流光裂隙，门脚仍对应原传送交互点。流光由独立的模拟时钟驱动，不随角色切换动作重置；第五层使用通关文字。离屏预览为 `target/portal-style-preview.png`。
