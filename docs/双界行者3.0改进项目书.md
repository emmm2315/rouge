# 双界行者 3.0 改进项目书

版本日期：2026-09-14。本文件保留 A/B 阶段设计背景；隐藏路线的当前实现以 `README.md` 和 `2026-09-15-progress-and-hidden-room-update.md` 为准。

## 目标与核心决策

两界共享一套敌人，而不是各自拥有一批只能在本界交战的敌人。敌人的实体、位置、生命、灼痕、索敌和施法进度在切界前后连续保留。玩家切换形态以利用弱点、衔接攻击和获得强化防御。地图生成、房间连接与相位墙布局继续沿用现有实现。

## A 共享状态与敌人重构

选用“光界铺灼痕、影界引爆”作为主循环，不同时加入扣血透支路线，避免多个资源惩罚互相叠加。两形态继续共用现有攻击充能和相位能量。

光攻击命中造成伤害并增加一层灼痕，上限三层；每次命中将有效期刷新为六秒。影攻击命中一次性消耗全部灼痕，每层增加 0.4 倍基础影伤的伤害系数，并回复八点相位能量。近战、影刃与现有范围伤害统一走伤害结算入口，不另造一套血条。灼痕按游戏时间衰减，暂停不推进；目标死亡或离房后随实体销毁，切界与首领换形不清空。

| 敌人类别 | 物种 | 克制规则 |
| --- | --- | --- |
| 弱光 | 狼、孢子、翼蝠、蛛后 | 光攻击系数 ×1.35，影攻击系数 ×0.85 |
| 弱影 | 灯灵、法师、处刑者、螳爵 | 影攻击系数 ×1.35，光攻击系数 ×0.85 |
| 光影破防 | 傀儡、甲虫、鸣钟者、守望者、炮蟹、古树、术士 | 普通攻击系数 ×0.5，引爆灼痕的影攻击系数 ×1.5，再加灼痕额伤 |

协同敌人采用强减伤而非绝对免疫，允许单形态低效率击杀，避免新手或充能不足时形成死锁。弱点文字与灼痕层数直接显示在敌人上方。

最终伤害沿用装备、方向护甲、难度与防御规则；新增系数为“武器段系数 × 克制倍率 + 灼痕层数 ×0.4”。灼痕额伤不再次叠乘克制倍率。一次伤害包只消费一次标记，不递归引爆或重复返能。

敌人的世界字段保留为招式形态、素材和原生地形碰撞属性，不再作为能否看见、索敌、造成伤害或被攻击的门槛。首领半血换形仍改变其招式阶段；换形锁定期间不移动或施法。

## B 双档切界与攻击衔接

| 项目 | 普通切界 | 强化切界 |
| --- | --- | --- |
| 条件 | 相位不足 100，包含零能量 | 相位达到 100 |
| 消耗 | 不消耗已有相位 | 消耗 100 相位 |
| 防御 | 无脉冲，无新增无敌 | 半径 118 清除可清弹幕，0.3 秒无敌 |
| 代价 | 0.3 秒内普通移速 ×0.65 | 消耗全部相位 |
| 操作 | Tab，统一 0.3 秒切界冷却 | Tab，统一 0.3 秒切界冷却 |

切界成功才清除玩家临时攻击并取消攻击后摇；未落下的前摇和延迟补击取消，已支付的攻击充能不返还。取消后可立即发动新形态攻击，仍受攻击充能约束。目标世界找不到安全落点时不扣能量、不取消攻击、不发脉冲。死亡后不能切界。

敌人的弹幕、预警、索敌和命中去重不因普通切界清除。两形态都能受到同一批敌方攻击伤害；玩家需要走位、冲刺或强化脉冲防守。HUD 相位行区分“切界”“强化”“减速”。

## C 形态入口与隐藏路线（已实施）

每层在现有节点图中保留一个可复现的 `HIDDEN` 房间，不增加主线层数或替换 Boss 收尾。隐藏房通过来源房间的隐藏出口连接，目标房保存由种子决定的 `requiredEntryForm`（光界或影界）；来源房的普通出口和 Boss 路径仍按原规则工作，因此隐藏路线始终是可选支线。

隐藏出口只在玩家真实跨门时检查 `requiredEntryForm`，原地切界不会触发进入。来源房为战斗房时必须先清场；错误形态或未清场到门口均保持在原房间，不消耗状态、不永久锁死。只有入口形态匹配时，暗门、来源房小地图提示和隐藏房节点才显示；正确形态跨门后标记目标房已访问，并清理跨房临时战斗状态。

隐藏房奖励由房间 `RoomLoot` 保存本局触发记录，第一次进入生成一次性奖励；离房重进不会重新生成或重复发放。小地图只在入口形态匹配时显示隐藏出口与隐藏节点；进入后以菱形图标标识隐藏房。主线门、Boss 传送门与通关条件均不依赖隐藏路线。

回归验收包括：同种子稳定生成隐藏房与入口条件、正确形态跨门触发、错误形态不触发且可重试、原地切界不误触发、奖励只生成一次、小地图提示，以及主线仍可到达 Boss 并通关。

## 架构与迁移

Enemy 保存灼痕；EnemyKind 提供克制分类；EnemySystem 负责共同战场、统一伤害与首领阶段；WorldShiftSystem 决定切界档位；Player 保存减速和无敌计时；PlayerAttackSystem 提供取消入口；GameSession 组织安全落点、脉冲和取消；GameRenderer 展示弱点、层数和切界状态。数值集中于 GameConfig 与 Affinity。

不复制敌人、不重新生成地图、不迁移本地账户档案。既有装备仍使用同一攻击方案系统。旧测试中“异界敌人静止”和“切界丢失目标”断言改为连续追击与持续索敌，其余原有回归测试保留。

## 验收与调优

自动验证光影攻击命中同一实体、灼痕封顶和到期、跨形态保留、引爆一次返能、弱点倍率、双档切界、减速到期、强化无敌、攻击取消和首领换形锁定。全量运行 Maven 测试并记录实际结果。

人工验收重点为连续光影连段的手感、弱点文字可读性、相位墙附近战斗和五层全流程。敌人全部活跃后总压迫会增加，战斗房改为 1～3 波、每波简单/标准 2～3 只、困难 2～4 只、屌炸天 3～4 只，波间休息 1.2 秒，全部波次完成才开门；后续以单房耗时、玩家承伤、切界频率和引爆占比调节数量与攻击频率。本次没有声称已完成人工试玩或最终数值平衡。

### 障碍布局与入场缓冲（2026-09-13）

战斗房扩大可用布局范围，尝试生成 6～9 组方柱、长掩体、L 形和 T 形掩体，事件房尝试 3～5 组。实际数量根据空间与连通性回退，不为了凑数封死通道。普通房障碍离区域边缘至少 96 像素，组间至少 96 像素；首领房保留 144 / 112 像素的宽通道。掩体以两界共有为主，搭配少量相位专属障碍，让绕行与切界各有作用。

布局完成后，用实际导航距离场检查两界中玩家及精英体型的连通性；首领房额外使用首领体型。检查失败时减少障碍。入口、奖励房和商店继续保留无障碍布局。

普通怪出生点距玩家至少 260 像素，避免与其他怪物重叠；出生后 0.8 秒显示“现身中”，不移动、不发起攻击。该规则覆盖初次入房、后续波次与事件伏击；首领及其召唤继续使用各自原有出场规则。
