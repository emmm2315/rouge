# 2026-09-15 隐藏路线、档案进度与成就同步说明

本文记录当前代码已经落地的规则，用于覆盖旧设计稿中“隐藏入口固定影界”与“图鉴尚未接入”的历史描述。实现基线为 `5e9df94`。

## 隐藏房

- 每层仍只生成一条可选的隐藏支路，不会取代 Boss 房或层间出口。
- 目标隐藏房的 `requiredEntryForm` 由本局种子决定，可为光界或影界。
- 来源房若为战斗房，必须清空敌人后才允许进入隐藏出口；这样无法在战斗中进入隐藏房。
- 只有玩家当前形态满足入口要求时，场景中的暗门、来源房的小地图入口提示和隐藏房节点才显示；切换到另一形态后会一起隐藏。
- 错误形态或未清场只会拒绝这次过门，不会消耗奖励或阻塞主线。首次进入隐藏房仍奖励 20 金币，重进不重复。

对应实现位于 `RoomNavigationSystem` 的过门校验，以及 `GameRenderer` 的隐藏门和小地图绘制逻辑。`HiddenRouteTest` 覆盖了“未清场不能进入、清场后才能进入”的回归场景。

## 本地档案与道具图鉴

`PlayerProgress` 使用本地 Java Preferences 保存三类跨局进度：已发现装备、已解锁成就、已击败的 Boss 种类。它不保存局内地图、战斗状态或背包。

道具图鉴列出全部 21 件装备，但只有实际拾取过的装备才会显示自身图标、基础属性和重复装备的强化说明；未发现项不会泄露名称或属性。图鉴为三列卡片，水平滚动已关闭，仅在内容高度超出时提供细窄的竖向滚动条。
