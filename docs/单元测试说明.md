## 4. 测试模块

| 模块 | 代表测试类 | 验证内容 |
| --- | --- | --- |
| 输入与玩家 | `InputStateTest`、`PlayerTest`、`PlayerDashTest` | 输入归一化、移动、冲刺、边界和死亡状态 |
| 动画与渲染 | `PlayerAnimationTest`、`WalkCycleTest`、`TextLayoutTest` | 动画状态、步态、HUD 文本布局和离屏渲染 |
| 技能与普攻 | `PlayerAbilitySystemTest`、`PlayerAttackSystemTest`、`WeaponAttackProfileTest` | Q/E 技能、R 终结技、蓝量、相位、冷却、弹体和多装备兼容 |
| 敌人与 Boss | `EnemySystemTest`、`EnemyDamageTest`、`MonsterExpansionTest`、`BossSummonTest` | 敌人属性、受击框、技能、召唤、寻路、弹幕和 Boss 名册 |
| 地图与房间 | `MapGeneratorTest`、`RoomLayoutTest`、`RoomFlowFieldTest`、`RoomNavigationSystemTest` | 固定种子、房间连通、障碍物、墙体、门和距离场 |
| 掉落与成长 | `RoomContentSystemTest`、`AccessoryEffectTest`、`ShieldTest` | 宝箱、商店、事件、装备替换、金币、药剂、护盾和属性叠加 |
| 流程与结算 | `GameSessionTest`、`HiddenRouteTest`、`HitReactionIntegrationTest` | 换房、隐藏房、清房、层推进、受击和跨层状态 |
