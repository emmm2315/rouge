# 《双界行者》详细设计

## 1. 输入与场景状态

`GameView` 将窗口坐标转换为 1280×960 逻辑坐标，并把输入交给 `GameController`。控制器维护按键边沿状态，避免 JavaFX 长按产生重复动作。

| 输入 | 模型入口 | 规则 |
| --- | --- | --- |
| Q | `GameSession.tryUseAbility(false, ...)` | 当前形态技能一，消耗蓝量并进入独立冷却 |
| E | `GameSession.tryUseSkill(1, ...)` | 当前形态技能二，消耗蓝量并进入独立冷却 |
| R | `GameSession.tryUseAbility(true, ...)` | 相位达到 80 才能释放，释放后扣除 80 并进入 30 秒冷却 |
| Ctrl | `GameSession.tryShiftWorld(false)` | 免费普通切界，共用 0.3 秒冷却 |
| Shift+Ctrl | `GameSession.tryShiftWorld(true)` | 满相位强化切界，清弹并短暂无敌 |
| F | `GameSession.requestInteract()` | 拾取、开箱、事件、商店二次确认、传送门 |
| Space | `Player.startDash(...)` | 沿输入方向闪避，冲刺期间免伤 |

死亡状态和结算状态在控制器入口提前返回；死亡结算只允许点击按钮，通关结算保留快捷键作为便利操作。

## 2. 游戏循环

```text
GameLoop 60Hz
  ├─ 读取 InputState
  ├─ GameSession.update(...)
  │   ├─ Player：移动、蓝量/相位恢复、冲刺、动画
  │   ├─ PlayerAttackSystem：普攻、弹体、命中去重
  │   ├─ PlayerAbilitySystem：技能/终结技前摇与多段结算
  │   ├─ EnemySystem：索敌、寻路、施法、召唤、受击
  │   ├─ EnemyProjectileSystem：弹幕、反弹、清除
  │   ├─ RoomContentSystem：掉落、宝箱、商店、事件、交互
  │   └─ RoomNavigationSystem：墙体、障碍物、门和距离场
  └─ GameRenderer.render()
      ├─ 当前世界房间与障碍物
      ├─ 玩家/敌人/弹体/预警/特效
      ├─ HUD、小地图、交互提示
      └─ 暂停或结算覆盖层
```

## 3. 战斗与资源规则

- 玩家基础生命 100、基础护盾 30；护盾先承伤，溢出伤害进入生命。
- 技能蓝量基础上限 16，每次技能消耗 6，每 1.5 秒恢复 1 点。
- 相位范围 0～100，自动恢复 0.5 点/秒；普通敌人、精英和 Boss 按类型提供不同击杀相位。
- 光攻击最多叠加三层灼痕；影攻击消耗灼痕，每层增加 0.4 倍基础影伤系数。
- 每个伤害包携带自己的系数、世界属性和命中策略，多段招式使用 `HitIds` 去重。
- 墙体和障碍物同时参与移动碰撞、弹体碰撞、敌人视线和技能可见性判断。

## 4. 房间与交互

`RoomNavigationSystem` 负责房间区域、门、墙、障碍物和距离场。战斗房未清空时门关闭，敌人全部清除后解锁并生成宝箱。`RoomContentSystem` 对交互目标按距离排序，只在 `INTERACT_RADIUS` 内显示 F 提示。

装备栏满时进入换装面板：按 1/2/3 选择替换槽，Esc 取消；被替换装备作为普通掉落留在原地。金币自动结算，装备、药剂、相位碎片和宝箱均需 F 交互。

## 5. 音频与设置

`AudioManager` 使用 JavaFX `MediaPlayer` 播放 `menu.mp3`、`exploration.mp3` 和 `boss.mp3`，按登录/菜单、普通探索、未清空 Boss 房切换并循环播放。音乐音量由设置监听器实时同步。当前版本的音效音量设置保留为配置项；若没有接入独立音效资源，答辩中应明确说明，不宣称已完成音效播放。

## 6. 测试与风险控制

- 模型层优先用 JUnit 验证资源、状态机、数值、边界和命中规则。
- 固定种子验证地图、房间内容、Boss 名册和奖励可复现。
- JavaFX 离屏预览单独执行，生成角色、传送门和技能截图。
- 人工 P0 测试覆盖登录、开始游戏、移动、战斗、技能、切界、交互、Boss、结算、音频、全屏和窗口缩放。
- 已知风险：窗口全屏/缩放、音频设备、鼠标灵敏度、复杂障碍物寻路需要在答辩前实机复核。
