# 《双界行者》概要设计

## 1. 项目定位

《双界行者》是一款基于 Java 21 与 JavaFX Canvas 的单机俯视角 Roguelike 动作游戏。玩家在光、影两个世界之间切换，在共享战场上利用灼痕、克制、技能、终结技和装备组合完成五层探索。

本文是答辩交付物中的概要设计，规则以当前 `main` 分支 HEAD `a7297e2` 和《双界行者》项目需求说明书为准。

## 2. 总体架构

系统采用“模型—控制器—视图”分层：

```text
Launcher / App
      │ 场景生命周期、BGM 场景切换
      ▼
GameView ── GameController ── GameSession
   │             │                │
   │             │                ├─ Player / Enemy / Boss
   │             │                ├─ PlayerAttackSystem / PlayerAbilitySystem
   │             │                ├─ RoomContentSystem / RoomNavigationSystem
   │             │                └─ WorldShiftSystem / DungeonMap
   ▼             ▼
Canvas 渲染   InputState       AudioManager / Settings
```

- `model`：纯游戏规则与状态，不依赖 JavaFX。
- `controller`：把键盘、鼠标和场景生命周期转换为模型操作。
- `view`：Canvas、HUD、菜单、结算界面和提示的绘制。
- `audio`：MP3 BGM 的循环、淡入淡出和场景切换。
- `config`：集中保存游戏常量、房间参数、难度和设置默认值。
- `resources`：角色、敌人、特效、装备图标、UI 样式和音频资源。

## 3. 核心玩法闭环

1. 玩家用昵称登录，进入主菜单选择难度与种子。
2. 生成五层可复现房间图，入口房、战斗房、奖励房、商店、事件房、Boss 房和可选隐藏房均由种子决定。
3. 在战斗房中使用普攻、Q/E 技能、R 终结技、闪避和 Ctrl 切界。
4. 光影两界共享敌人位置与生命；光攻击叠加灼痕，影攻击引爆灼痕并获得额外收益。
5. 清空战斗房后解锁房门并生成宝箱；F 键用于拾取、开箱、事件、商店确认和进入传送门。
6. 击败 Boss 后进入下一层，第五层通关后进入结算；生命归零进入死亡结算。

## 4. 关键设计决策

- **共享战场**：切界不是切换两张地图，而是改变当前世界判定、玩家形态和敌我克制，避免状态分裂。
- **固定步长**：游戏模拟按 60 Hz 推进，暂停时冻结模拟时间，保证冷却、恢复、敌人行为和施法时序可复现。
- **输入防抖**：技能、交互、冲刺和切界均按“按下沿”触发，长按不会重复支付资源或重复购买。
- **资源与判定分离**：特效帧只负责视觉，伤害由技能参数、受击框、墙体视线和命中去重规则统一结算。
- **装备可组合**：多件改变普攻方式的装备可以同时启动，但不额外叠加百分比伤害，技能和终结技几何不被普攻方案污染。

## 5. 交付与验证口径

- 当前操作：WASD/方向键移动，鼠标瞄准与普攻，Q/E 技能，R 终结技，Ctrl 普通切界，Shift+Ctrl 强化切界，Space 闪避，F 交互。
- 登录仅保留昵称，不要求密码。
- 当前回归基线：`274` 条自动化测试，`274` 通过、`0` 失败、`1` 跳过；离屏角色预览需显式开启 `-Dplayer.preview=true`。
- AI 辅助代码必须经过源码审查、单元测试和固定种子回归；答辩归档保存测试原始输出，不只保存手工汇总数字。
